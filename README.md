# موقع مدرسة النهروان

## تشغيل الموقع محلياً

1. ثبّت Node.js LTS، ثم افتح نافذة طرفية جديدة.
2. من مجلد المشروع شغّل `npm install`.
3. شغّل `npm start` وافتح `http://localhost:3000`.

## النشر على GitHub Pages

يوجد سير عمل في `.github/workflows/pages.yml` يختبر المشروع ثم ينشر صفحات HTML وملفات JavaScript والصورة الثابتة من جذر المشروع. في إعدادات المستودع، افتح **Settings > Pages** واختر **GitHub Actions** كمصدر للنشر، ثم ادفع التغييرات إلى فرع `main` أو `master` أو شغّل سير العمل يدوياً من تبويب **Actions**.

افتح رابط Pages الذي يظهر في نتيجة النشر. إذا كان المستودع مشروعاً وليس مستودع المستخدم الرئيسي، يكون الرابط عادةً `https://<username>.github.io/<repository>/` وليس `https://<username>.github.io/`.

صفحات الموقع وتحديثات المدرسة متاحة مباشرة دون حسابات. لا يستخدم الموقع قاعدة بيانات أو ملفات JSON أو API لتحميل الأخبار أو نشرها. تُقرأ التحديثات محلياً من `updates-data.js`، ويُعرض محتواها كنص آمن ولا يُفسر كـ HTML.

زر «إنشاء إعلان» متاح في لوحة الإعلانات بالصفحة الرئيسية وصفحة التحديثات. يتيح تنسيق النص وإضافة روابط وصور، ويحفظ الإعلانات في التخزين المحلي للمتصفح لتبقى عند التنقل بين الصفحات أو إعادة فتح الموقع على الجهاز نفسه. لا تُرسل الإعلانات إلى الخادم ولا تظهر على أجهزة الزوار الآخرين. يمكن أن يؤدي مسح بيانات المتصفح إلى حذفها.

لإضافة تحديث يظهر لجميع الزوار، عدّل المصفوفة `updates` في `updates-data.js` وأضف عنصراً يحتوي `title` و`content` و`author` و`created_at`، ثم أعد نشر ملفات الموقع.

الخادم يستمع محلياً على `127.0.0.1` افتراضياً، ويرتبط بـ `0.0.0.0` عند ضبط `NODE_ENV=production`. شغّل الموقع العام خلف HTTPS في الإنتاج.
